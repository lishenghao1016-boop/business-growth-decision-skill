# 品牌升级方案审查

## 示例问题

```text
使用 $business-growth-decision 审查我们的品牌升级方案。

背景：公司年收入2亿元，过去两年增速从25%降到8%。市场部希望投入800万元，
更新品牌定位、视觉系统和传播内容，并认为知名度不足是增长放缓的主因。
目前只有一份消费者调研和销售团队访谈，没有品牌漏斗、流失原因、价格接受度
或接触点体验数据。请用“方案审查”模式回答。
```

## 应重点体现

- 不把换视觉或口号直接等同于品牌升级；
- 判断增长放缓是否真的由品牌问题主导；
- 把预算拆成诊断、验证、实施和放大阶段；
- 明确批准条件、负责人、指标、复盘日期和退出条件；
- 不虚构知名度、转化率或销售增长阈值。
